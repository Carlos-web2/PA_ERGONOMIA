# Guia de Contribuição

Diretrizes para contribuição no projeto de PA de Ergonomia da ETEC.

## Padrões de Desenvolvimento
1. Mantenha o código HTML semântico e identado.
2. Utilize a folha de estilos `style.css` para formatação visual.
3. Funções e lógicas interativas devem ser mantidas no arquivo `script.js`.
4. Alterações conceituais devem respeitar as diretrizes da NR-17 e normas técnicas associadas.

## Fluxo de Trabalho
1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração:
   ```bash
   git checkout -b feature/nome-da-feature
