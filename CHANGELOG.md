# Changelog

Todas as alterações notáveis deste projeto serão documentadas neste arquivo.

## [1.0.0] - 2026-10-23

### Adicionado
- Estrutura inicial do projeto em múltiplas páginas para a disciplina de Projetos Acadêmicos (PA) da ETEC.
- Página inicial (`index.html`) com apresentação e contextualização da equipe.
- Módulo de Condições Ambientais (`item1_ambiente.html`) com verificação em JavaScript para Lux e decibéis.
- Módulo de Posto de Trabalho (`item2_posto.html`) contendo calculadora antropométrica paramétrica.
- Módulo de Gestão de Pausas e Fadiga (`item3_pausas.html`) com temporizador interativo.
- Página de Referências Bibliográficas (`referencias.html`) conforme ABNT NBR 6023 e padrões ISO.
- Folha de estilos unificada (`style.css`) e script de funções (`script.js`).
- Documentação técnica e guia de uso na pasta `docs/`.
