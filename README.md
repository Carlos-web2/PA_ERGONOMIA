# Projeto de PA: Portal Ergonômico e Avaliação Normativa

Sistema web para diagnóstico de condições ergonômicas em ambientes de trabalho e estudo, desenvolvido conforme a NR-17 e as normas internacionais ISO/TS 20646, ISO 8995-1 e ISO 9241.

## Sobre o Projeto

Este projeto foi desenvolvido para o componente curricular de Projetos Acadêmicos (PA) do curso técnico da ETEC. O portal tem como objetivo auxiliar no diagnóstico de riscos ergonômicos e na promoção da saúde ocupacional por meio de ferramentas interativas e fundamentação teórica baseada em normas técnicas.

### Funcionalidades
- Análise de Iluminância e Ruído: Verificação de conformidade com os limites da NR-17 e ISO 8995-1.
- Calculadora Antropométrica: Dimensionamento de mesas e assentos com base na altura do usuário (ISO/TS 20646).
- Timer Pomodoro Ergonômico: Gestão de ciclos de foco e intervalos para prevenção de fadiga e LER/DORT.
- Referências Bibliográficas: Listagem de fontes formatada segundo a ABNT NBR 6023.
