# Guia de Utilização do Portal

Instruções operacionais para navegação e uso das ferramentas do sistema.

## Navegação
O menu superior presente em todas the páginas permite o acesso aos seguintes módulos:
- Início: Contextualização, objetivos e equipe.
- 1. Condições Ambientais: Simulador de iluminância e ruído.
- 2. Posto de Trabalho: Calculadora antropométrica.
- 3. Pausas e Fadiga: Temporizador de intervalos.
- Referências: Bibliografia e normas técnicas.

## Utilização das Ferramentas

### Avaliação Ambiental
1. Acesse a página de Condições Ambientais.
2. Insira o valor de iluminância obtido (em Lux).
3. Insira o valor do ruído mensurado (em dB).
4. Clique no botão de execução para visualizar o diagnóstico baseado na NR-17.

### Calculadora de Posto de Trabalho
1. Acesse a página de Posto de Trabalho.
2. Insira a altura do usuário em centímetros.
3. Clique no botão de cálculo para obter as dimensões recomendadas de mesa e assento.

### Temporizador de Pausas
1. Acesse a página de Pausas e Fadiga.
2. Utilize o botão de início para disparar o ciclo de foco de 25 minutos.
3. Utilize os botões de pausa ou reinício conforme necessário.
